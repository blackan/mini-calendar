Privacy Policy - mini calendar

mini calendar is a personal-use application, used only by its owner.

Data accessed

With the user's permission, the app accesses Google Calendar data (the calendar list and calendar events) solely to view, add, edit and delete the user's own calendar events.

Storage

Data and access tokens are stored only on the user's own device. Nothing is stored on any external server operated by this app.

Sharing

Data is not shared with, sold to, or transferred to any third party.

Calendar data is used only to fulfil the owner's own requests through the owner's personal AI assistant (Anthropic Claude); it is not used for any other purpose.

Revoking access

The user can revoke the app's access at any time from their Google Account (https://myaccount.google.com/permissions).
